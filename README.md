# مقهى الفردوس — Cafe El Firdaous

نظام محلي لإدارة المبيعات ونقطة البيع والزبائن والولاء والمصاريف والتقارير باستخدام PHP 7.3+ وMySQL.

## التثبيت
1. انسخ المشروع إلى مجلد Apache، مثل `htdocs/cafe-elfirdaous`.
2. أنشئ قاعدة البيانات باستيراد `sql/schema.sql` ثم `sql/seed.sql` عبر phpMyAdmin أو MySQL.
3. عدّل بيانات الاتصال في `config/database.php`، وعدّل `APP_URL` في `config/config.php` إلى مسار المشروع.
4. افتح `http://localhost/cafe-elfirdaous/` وسجّل الدخول باستخدام `admin` / `password`.
5. أنشئ كلمة مرور إدارية جديدة من صفحة المستخدمين، واحذف/عطّل الحساب التجريبي عند اللزوم.

## المزايا
- نقطة بيع تسجل البنود بسعر التكلفة وقت البيع، وتدعم الزبون والرصيد والنقاط وطباعة فاتورة.
- إدارة الزبائن والطبقات، وقواعد الولاء قابلة للتعديل من الإعدادات.
- سجل حركات الديون والإيداعات والمصاريف.
- تقارير إيرادات وتكلفة بضاعة وربح إجمالي وصافي مع تصدير CSV.
- صلاحيات مدير وكاشير، PDO prepared statements، كلمات مرور مشفرة، جلسات وCSRF.

## ملاحظات
- رمز العملة الحالي مضبوط في `config/config.php`؛ تحديث رمز العملة يحتاج تغيير الثابت هناك.
- يشترط تمكين PDO MySQL وPHP sessions. الواجهة تستخدم Bootstrap عبر CDN.
- الرصيد الموجب هو رصيد مقدم للزبون، والسالب دين عليه. تسديد الدين يزيد الرصيد باتجاه الصفر.
- غيّر كلمة المرور التجريبية قبل الاستخدام الحقيقي، واستخدم HTTPS إذا نُشر النظام على شبكة عامة.
